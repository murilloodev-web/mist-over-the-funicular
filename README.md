# The Mist over the Funicular

*An investigation grimoire for **Call of Cthulhu 7th Edition**, set in Paranapiacaba, Brazil, May–July 1974.*

In 1974 the Brazilian federal railway begins winding down a century-old cable railway on the Serra do Mar to save money. Nobody in Brasília knows what that railway was really carrying.

**Read it online:** `https://murilloodev-web.github.io/mist-over-the-funicular/`

---

## What's inside

- **27 linked pages**: places, Mythos (including the Mist Contact rules), factions, three pre-generated investigators, three endings.
- **Fact & Fiction**: every historical claim is cited to a real source; everything invented is tagged *Fiction*.
- **Timeline** from 1859 to 2001, with history and scenario events side by side.
- **Scenario Flow**: the branching investigation as a clickable diagram.
- **Procedural pixel-art banner**, generated by Lua at build time.

## How it's built

The grimoire is written as **plain Lua data**, and a small Lua build script turns it into a static website.

```
data/
  pages.lua          narrative pages (light markup: [[links]], {{citations}}, **bold**)
  investigators.lua  CoC 7e character sheets
  sources.lua        real-world references
  timeline.lua       dated history + fiction events
  flow.lua           the scenario as a graph of scenes and exits
  contact.lua        the Mist Contact track (checked for gaps and overlaps)
tools/banner.lua     procedural 16-bit banner (dithered sky, fog, incline, Castelinho)
assets/style.css     dark 16-bit theme
build.lua            validator + static site generator  →  docs/
DESIGN-BRIEF.md      visual prototypes still to be drawn
```

`build.lua` refuses to build if the content is inconsistent:

- an internal link or a citation points to something that doesn't exist, or a source is never cited;
- a history entry in the timeline has no source (or a fiction entry has one);
- an investigator's printed HP or Sanity disagrees with the CoC 7e formulas (it also computes MP, Move, Damage Bonus, Build and Hard/Extreme values);
- a scene in the flow can't be reached from the start, or a path dead-ends before an ending;
- the Mist Contact tiers leave a gap or overlap anywhere between 0 and 10.

```
$ lua build.lua
✓ 27 pages, 14 sources, 19 timeline entries
✓ scenario graph: 10/10 scenes reachable, 3 endings, no dead ends
✓ 3 investigator sheets match CoC 7e derived-stat rules
✓ mist contact track: 7 tiers cover 0–10 with no gaps
✓ wrote site to docs/
```

Use `lua build.lua --check` to validate without writing files. It needs Lua 5.4 and no other dependencies.

## Publishing

Every push to `main` runs `.github/workflows/pages.yml`: GitHub Actions installs Lua 5.4, runs `lua build.lua` (so a broken link, a wrong stat or a dead-end scene fails the build) and publishes `docs/` to GitHub Pages. The generated `docs/` folder is not committed.

To build locally, run `lua build.lua` and open `docs/index.html`.
